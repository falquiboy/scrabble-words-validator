# Información sobre el archivo FILE2017.kwg

Este archivo parece ser un archivo KWG (formato binario GADDAG) que ya existe en tu proyecto.

## Análisis del archivo

El archivo FILE2017.kwg que tienes en la raíz del proyecto probablemente contiene:
- Un diccionario de Scrabble en español
- Formato binario KWG (4 bytes por nodo)
- Estructura GADDAG para búsquedas eficientes

## Cómo usarlo

1. Copia el archivo a la carpeta public para acceso web:
```bash
cp FILE2017.kwg public/FILE2017.kwg
```

2. Úsalo con el KWGReader:
```typescript
import { KWGReader } from '@/services/duplicada/KWGReader';

// Cargar el KWG
const kwg = await KWGReader.loadFromUrl('/FILE2017.kwg');

// Verificar palabras
console.log(kwg.isValidWord('CASA')); // true/false
```

## Nota importante

Este archivo KWG probablemente NO tiene nuestro mapeo de caracteres especiales (Ç para CH, K para LL, W para RR). Necesitaremos:

1. Verificar qué mapeo de tiles usa
2. Ajustar nuestro TILE_TO_CHAR en KWGReader.ts
3. O regenerar el KWG con nuestro mapeo
